# 📊 Экспортер CSV Отчетов (с Web-интерфейсом)

Микросервис на Spring Boot для автоматической генерации и скачивания CSV-отчетов. Приложение интегрируется с внешним API, обрабатывает полученные данные и предоставляет **удобную веб-страницу** для скачивания готовых отчетов в один клик.

## 🚀 Возможности
- Интеграция с внешним API для получения актуальных данных.
- Генерация отчетов в формате `.csv` "на лету".
- **Минималистичный веб-интерфейс** для удобного взаимодействия пользователей.
- Выгрузка отчетов по трем категориям:
    - 🏃‍♂️ Игроки
    - 🛡 Команды
    - ⚔️ История матчей
- Полностью контейнеризировано (Docker & Docker Compose).

## 🛠 Стек технологий
- **Java 17 / Spring Boot 3** (Web, RestTemplate)
- **Шаблонизатор** (генерация UI страницы)
- **MapStruct / Lombok** — для маппинга DTO
- **Docker / Docker Compose**

## ⚙️ Конфигурация и запуск

Для запуска проекта вам понадобится только установленный [Docker](https://www.docker.com/) на вашей машине.

### 1. Настройка окружения
В корневой папке проекта создайте файл `.env` (или переименуйте `.env.example`) и укажите URL внешнего API, откуда сервис будет брать сырые данные:

```env
API_BASE_URL=http://адрес-внешнего-api.com
```

### 2. Запуск через Docker Compose
Откройте терминал в папке с проектом и выполните команду:

```bash
docker-compose up --build -d
```
Сервис поднимется и будет доступен на порту **8080**.

## 💻 Использование

Вам не нужны сторонние программы вроде Postman. Всё работает прямо в браузере.

1. Откройте браузер и перейдите по адресу:  
   👉 **http://localhost:8080/report**
2. Перед вами откроется панель с кнопками.
3. Нажмите **"Скачать отчёт"** под нужной категорией (Игроки, Команды или История матчей).
4. Браузер автоматически начнет загрузку `.csv` файла с актуальными данными.

## 📡 Для разработчиков (Прямые API Endpoints)

Если вам нужно интегрировать скачивание отчетов в другой сервис или скачивать их через `cURL`/скрипты, вы можете использовать прямые GET-запросы, к которым привязаны кнопки интерфейса:

| HTTP Метод | Endpoint (примерные ссылки) | Описание |
| :--- |:----------------------------| :--- |
| `GET` | `/report`                   | Отдает HTML-страницу интерфейса |
| `GET` | `/report/players/download`  | Прямое скачивание CSV по игрокам |
| `GET` | `/report/team/download`     | Прямое скачивание CSV по командам |
| `GET` | `/report/match-history/download`  | Прямое скачивание CSV по матчам |
